Banking technology Lab
Definition
As part of the Banking Technology lab, students will develop 
multiple small applications related to the banking domain. 
Integrating these applications, which will be built and deployed 
in the Cloud using Azure App Service. 
The outcome of this lab would be a fully functional banking 
application that is hosted on the cloud.

Banking Technology Lab
Modules – User Registration and Banking Application 
User Registration and Banking System → Admin function
• Application to register a user 
•
Encryption and Decryption of the password using salt and hashing
•
Register the user in the Customer Module and use the customer ID as a User.
•
Multiple user ID options, e-mail, and phone number can be used instead of the 
customer ID.
•
Use of a strong password policy like minimum length of 8, with at least 1 number, 1 
special character, and 1 Capital letter.
• Application to verify the user and allow access to the system
• Both the User-ID and password must be entered to log in successfully.
• Integrated system consisting of Customer, Product and Pricing, Fixed Deposit 
Calculator, Fixed Deposit, Report Modules
• SSO for all applications, each application should be able to log in and work 
independently
• Set a limit to auto logoff if the page is idle for a predefined time. E.g. 5 minutes

Banking technology Lab
Modules – Product and Pricing
Product and Pricing → Admin function 
Define products offered by banks like CASA, TD, Unsecured Loan, etc. 
Defining business rules,  guiding behaviors, roles, relationships, etc for the products
A generic way of designing an application to accommodate a varied set of values.
Functionality with a few of the business rules -  minimum age, Term for Deposits, Deposit 
and Withdrawal Amount limits, etc.
Different Life cycle statuses for different product types 
Different interest types(Debit for Loans/Credit for Deposits) for different product types. 
Different rates based on customer attributes like Senior citizen, Employee, etc.
Different types of Fees – Periodic, one-time, event-based fee(e.g. Withdrawal from ATM), 
etc.
Different balance types, transaction types for different products.
Understand how business rules are defined and built.
Defaulting of product definition on accounts, resetting of values on the account, 
etc.E.g. Term, amount, etc., on an FD account.
